# ⭐ Reverse Star Triangle Pattern in C

## 📌 Description
This program prints a reverse star triangle pattern using nested loops in C language.

---

## 💡 Pattern Output
* * * 
* *
* 
---

## 🧠 Concepts Used
- Nested loops
- Outer loop for rows
- Inner loop for stars
- Reverse looping

---

## ⚙️ Logic

- Outer loop decreases rows from n to 1
- Inner loop prints stars according to row value

---

## 💻 Language Used
- C Programming Language
